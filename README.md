# 시스템프로그래밍 팀6
스마트 등산 스틱

### 1. 목적
![그림1](/uploads/20fe67074372bdb2816c06af09f75ef5/그림1.png)


  코로나가 완화되고 실내 생활에 지친 많은 사람들이 밖으로 나오기 시작했다. 그에 힘입어 등산객들도 매우 많아졌다. 여기 수원 광교산만해도 19년도와 20년도 등산객 차이가 약 천 만명 정도나는 것을 확인할 수 있었다. 하지만, 그만큼 등산객 사고도 늘어난 것을 볼 수 있다.
 

 
![그림2](/uploads/a879f5d6cafc90d2162724f372cf518b/그림2.png)


  20~ 21년도 사고 발생건수는 1만 4,950건으로 꽤 많은 사고가 나는 것을 확인할 수 있었다. 이런 등산 사고들의 유형은 실족이 38.0%(941건 중 358건) 길을 잃고 헤매는 조난 24.9%(234건) 지병 등으로 인한 신체질환 16.4%(154건) 순으로 나타났다. 이런 사고들을 예방하기 위해 스마트 지팡이 주제를 선정하게 되었다.

### 2. 기능
- GPS 위치 추적 기능
- 지팡이간 통신 기능
- 자동 LED 점등
- 등산 완료 % 표시
- 지팡이 상황 녹화 기능

### 5. 개발환경
- 운영체제: Raspbian OS
- 에디터: VS Code
- 사용 언어: C
- 컴파일
    - server.c(서버 파이): gcc -o server server.c -lpthread -lm
    - client.c(지팡이 파이): gcc -o client client.c -lwiringPi -lpthread
    - client_test.c(통신 테스트 파이): gcc -o client_test client_test.c -lpthread
